## 📖 Project Overview

SmartCare HMS is a hospital management web application that allows hospitals and clinics to efficiently manage patients, doctors, appointments, and administrative tasks.

The system provides secure authentication, appointment booking, email notifications, and dashboard management for both patients and administrators.

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/00najmulhuda/SmartCare-HMS-Hospital-management-system-.git
```

### Move Into Project Directory

```bash
cd SmartCare-HMS-Hospital-management-system-
```

### Install Dependencies

```bash
npm install
```

### Run Backend Server

```bash
npm start
```
